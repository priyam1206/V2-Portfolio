# Priyam Trivedi | Personal Portfolio

Welcome to the repository for my personal portfolio website! This project is a highly interactive, performance-optimized web experience designed to showcase my work as a Full Stack Developer, Creative Technologist, and AI Specialist.

# ✨ Key Features

Custom Particle Physics Engine: A lightweight, highly optimized 2D canvas engine that morphs particles into tech-related symbols ({ }, </>, AI, px, py) with smooth lerping and physics-based mouse/touch repulsion.

Zero Scroll-Jitter Architecture: Canvas elements are strictly localized to their respective DOM sections to allow native browser scrolling, ensuring 60fps buttery-smooth performance.

Interactive Magnetic Contact Grid: The footer features a localized dot grid that magnetically reacts to user cursor movements, creating a deeply engaging tactile feel.

Fluid Responsive Typography: Utilizes modern CSS clamp() functions for seamless scaling across mobile, tablet, and desktop viewports.

Typewriter Effects: Custom JavaScript typewriter implementation for the contact email.

# 🛠️ Built With

This project was built from scratch without relying on heavy external libraries like Three.js or complex frontend frameworks to ensure maximum performance and complete control over the physics engine.

HTML5

CSS3 (Custom Grid/Flexbox layouts, clamp functions)

Vanilla JavaScript (ES6+)

HTML5 Canvas API (For particle physics and rendering)

Google Fonts (Inter)
